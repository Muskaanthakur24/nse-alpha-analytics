# NSE Alpha Analytics

**Professional Finance Analytics Dashboard** for Indian Stock Market (NSE)

Built as a **BCom + Data Science / Analytics** project with modern UI and real-time data.

![Dashboard Preview](https://via.placeholder.com/800x400?text=Dashboard+Preview)

## ✨ Features

- Live Stock Price Tracking (NSE)
- Technical Indicators (SMA, RSI)
- Company Fundamentals
- Professional Dark Theme UI
- Interactive Candlestick Charts
- Responsive Design

## 🛠 Tech Stack

- **Python** + **Streamlit**
- **yfinance** (for live NSE data)
- **Plotly** (Interactive Charts)
- **Pandas** (Data Processing)

## 🚀 How to Run Locally

```bash
# Clone the repo
git clone https://github.com/Muskaanthakur24/nse-alpha-analytics.git
cd nse-alpha-analytics

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run app.pyss
